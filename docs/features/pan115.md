# 115 云盘配置

115 网盘是所有资源存储和播放的基础。本指南将带你一步步完成从添加账号到自动化管理的完整配置。

## 前置条件

开始前请确保已有：
- 115 网盘账号（VIP 账号体验最佳）
- 可用的 115 Cookie，或手机 115 App 用于扫码登录

---

## 步骤 1：添加 115 账号

进入前端侧边栏 **网盘 → 115 助手**，页面以表格展示所有已配置的账号。

### 账号类型

:::: card-grid
::: card title="内置账号" icon="material-symbols:admin-panel-settings"
管理员配置，用于系统内部的转存、离线下载、Emby 302 播放。支持目录配置、副 Bot、同播复制、定时清理等完整功能。
:::
::: card title="自备账号" icon="material-symbols:person"
Emby 用户自行提供的 115 账号，仅需 Cookie 和回收站密码，用于自备模式播放。
:::
::::

### 内置账号配置

点击 **内置账号** 按钮，填写以下信息：

| 配置项 | 说明 |
|--------|------|
| **名称** | 配置标识名（如 `115-主号`） |
| **Cookie** | 115 网盘 Cookie，填写后点击右侧「测试」按钮验证有效性 |
| **转存目录** | 默认转存目标目录，通过目录选择器浏览 115 网盘目录树选择 |
| **离线目录** | 离线下载目标目录（magnet/ed2k 链接下载位置） |
| **备注** | 仅在 115 助手页面展示，便于区分账号用途 |

::: tip 获取 Cookie
推荐点击 Cookie 输入框旁的 **扫码**，用 115 App 扫码登录后自动填入 Cookie。也可以在浏览器中登录 115 网盘后，按 F12 打开开发者工具 → Application → Cookies → 找到 `UID` 和 `CID` 等关键字段，或直接使用浏览器插件导出完整 Cookie 字符串。
:::

### 账号信息检测

保存、创建、更新 Cookie 后，系统会自动同步账号信息。页面会展示：

| 信息 | 说明 |
|------|------|
| **VIP 状态** | 普通、VIP、年 V、永 V 等标签 |
| **到期时间** | 非永久 VIP 会展示到期日期 |
| **容量信息** | 总容量、已用容量、剩余容量和使用进度 |
| **检测时间** | 最近一次账号信息同步时间 |
| **错误原因** | 查询失败时展示错误，但不阻止保存 Cookie |

顶部或列表中的 **批量查询信息** 可手动刷新全部账号的 VIP/容量状态。

### 自备账号配置

自备账号仅需：
- **名称** — 配置标识名
- **Cookie** — 115 网盘 Cookie
- **回收站密码** — 清理回收站时的安全密码

---

## 步骤 2：配置副 Bot（可选，仅内置账号）

每个内置 115 账号可绑定一个独立的 Telegram 副 Bot，用于：
- 该账号的转存通知独立推送
- 用户通过副 Bot 执行搜索和命令

| 配置项 | 说明 |
|--------|------|
| **副 Bot Token** | 从 [@BotFather](https://t.me/BotFather) 获取的独立 Bot Token |
| **白名单** | 允许使用该副 Bot 的用户 ID 列表，留空不限制 |
| **Chat ID** | 副 Bot 发送通知的目标聊天 ID，配置 Token 时必填 |

---

## 步骤 3：配置同播复制（可选，仅内置账号）

当多个用户同时播放同一文件时，115 网盘存在单文件并发限制。同播复制会自动为后续用户创建文件副本，确保每个用户独立播放。

| 配置项 | 说明 |
|--------|------|
| **同播复制** | 开关。适合多用户共享同一 115 账号的场景 |
| **临时目录** | 副本文件的存储目录，默认 `/ResourceTool` |

---

## 步骤 4：配置定时清理

进入 **概览 → 插件库 → 115 回收站清理**。这里的任务和 115 账号一一对应：

| 配置项 | 说明 |
|--------|------|
| **启用定时清理** | 开关 |
| **清理 Cron** | 执行时间表达式，默认 `0 1 * * *`（每天凌晨 1 点） |
| **回收站密码** | 清空回收站的安全密码 |
| **立即清理** | 保存后可手动触发一次清理 |

::: tip 使用建议
多用户共享账号并开启同播复制时建议启用；全部用户都使用自备账号时通常不需要。回收站密码可以不填，此时只清理临时目录，不清空回收站。
:::

---

## 步骤 5：配置 Cookie 健康检查

115 Cookie 会定期过期，过期后转存、离线、302 播放等功能均会失效。健康检查可帮你及时发现失效账号。

进入 **概览 → 插件库 → 115 健康检查**：

1. 点击 **一键检测** 按钮，系统逐个调用 115 API 验证每个账号
2. 检测完成后每个账号显示状态：
   - <Badge type="tip" text="正常" /> — Cookie 有效
   - <Badge type="danger" text="失效" /> — 需要更新
3. 失效账号回到 **步骤 1** 更新 Cookie

::: tip 建议每周检查一次，或在发现转存/播放异常时优先检查 Cookie 状态。
:::

---

## 步骤 6：配置每日自动签到

115 网盘每日签到可获取积分和空间奖励。为每个账号配置自动签到，省去手动操作。

进入 **概览 → 插件库 → 115 签到**，为每个账号设置：

| 配置项 | 说明 |
|--------|------|
| **115 账号** | 选择要签到的内置账号 |
| **签到 Cron** | 例如 `1 0 * * *` 表示每天 00:01 执行 |

::: warning Cookie 有效性
签到依赖有效的 Cookie。如果签到持续失败，请先通过健康检查确认 Cookie 状态。
:::

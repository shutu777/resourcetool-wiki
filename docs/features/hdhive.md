# HDHive 助手

HDHive 是影视资源的搜索和解锁引擎，集成 TMDB 元数据，实现从搜索到转存的一站式体验。本指南带你完成从添加 API Key 到自动签到的完整配置。

## 前置条件

- HDHive 账号和 API Key（从 HDHive 网站获取）
- 至少配置好一个 [115 账号](/features/pan115/)

---

## 步骤 1：添加 HDHive API Key

进入侧边栏 **HDHive → HDHive 用户**，点击 **添加用户**：

| 配置项 | 说明 |
|--------|------|
| **API Key** | HDHive Open API 的 API Key |

保存后系统自动调用 HDHive API 获取用户信息和积分余额。

### 用户卡片展示

每张卡片显示：用户名、剩余积分、今日消耗、API Key（脱敏）、状态（<Badge type="tip" text="正常" /> / <Badge type="warning" text="额度不足" /> / <Badge type="danger" text="异常" />）。

### 负载均衡

配置多个 HDHive 用户后，系统按**剩余积分智能调度**：优先选择积分最充足的用户，单个用户积分耗尽时自动切换到下一个可用用户。点击顶部「刷新额度」可手动更新所有用户的积分数据。

---

## 步骤 2：搜索和解锁资源

进入侧边栏 **HDHive → 影视搜索**：

1. **搜索**：输入关键词，选择电影/电视剧类型，点击搜索
2. **浏览结果**：网格卡片展示 TMDB 搜索结果（海报、标题、年份、评分）
3. **查看详情**：点击卡片进入详情页，左侧为 TMDB 媒体信息，右侧为 HDHive 资源列表
4. **解锁资源**：每条资源显示分辨率、编码格式、文件大小、所需积分，点击「解锁」

解锁后系统自动处理：
- **115 分享链接** → 弹出 115 配置选择，一键转存到网盘
- **magnet / ed2k 链接** → 弹出 115 配置选择，提交离线下载任务

转存目录使用对应 115 配置的默认转存目录。

---

## 步骤 3：配置每日签到

HDHive 积分是解锁资源的货币，每日签到可获取免费积分。

进入侧边栏 **插件库 → HDHive 签到**，为每个 HDHive 用户配置：

| 配置项 | 说明 |
|--------|------|
| **启用自动签到** | 开关 |
| **签到时间** | 每日自动签到执行时间 |
| **签到模式** | 见下方说明 |

### 签到模式

:::: card-grid
::: card title="普通签到" icon="material-symbols:check-circle"
稳定获取固定积分，无风险。适合积分充裕或保守型用户。
:::
::: card title="赌狗模式" icon="material-symbols:casino"
随机获取积分，上限更高但有概率获得较少积分。适合追求高收益的用户。
:::
::::

::: caution 赌狗模式收益随机波动，极端情况下可能不如普通签到。请根据积分储备谨慎选择。
:::

### 手动签到

点击账号旁的「手动签到」按钮可立即执行一次签到，签到后显示获得积分和账户余额。

---

## 步骤 4：查看解锁记录

进入侧边栏 **HDHive → 解锁记录**，查看所有解锁历史和统计数据：

- **汇总卡片**：今日解锁次数、累计解锁数、消耗积分总数、独立用户数
- **记录列表**：按时间、资源名称、HDHive 用户、消耗积分、触发来源（手动搜索/频道监控自动解锁）、状态筛选
- 支持按关键词搜索和分页浏览

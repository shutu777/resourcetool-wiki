# HDHive 助手

HDHive 是影视资源的搜索和解锁引擎。最新版 ResourceTool 已切换为**中心网关授权模式**：不再保存 HDHive 个人 API Key，搜索、解锁、签到、Telegram 命令和频道监控都通过授权用户调用。

## 前置条件

- 已部署 ResourceTool，并能通过公网地址访问管理面板
- 已配置 [TMDB API Key](/features/system/)
- 至少配置好一个 [115 账号](/features/pan115/)

::: important 接入变化
旧版「填写 HDHive API Key」方式已下架。请在 **系统 → 系统配置 → HDHive 中心网关** 完成接入，再到 **HDHive → HDHive 助手** 进行授权。
:::

---

## 步骤 1：接入中心网关

进入侧边栏 **系统 → 系统配置**，找到 **HDHive 中心网关**。

| 配置项 | 说明 |
|--------|------|
| **中心网关** | 默认使用 ResourceTool 官方中心网关 |
| **RT 外网地址** | 授权完成后回跳到当前 RT，例如 `https://rt.example.com` |
| **一键接入并启用** | 自动注册当前 RT 实例并写入网关接入信息 |

保存成功后，系统会生成网关实例 ID 和密钥。之后 HDHive 用户授权、额度刷新、搜索解锁都走该网关。

::: tip 外网地址要求
RT 外网地址需要能被浏览器和中心网关访问。如果部署在内网，建议先配置反向代理或公网隧道。
:::

---

## 步骤 2：授权 HDHive 用户

进入侧边栏 **HDHive → HDHive 助手**，点击 **网关授权**。

授权完成后页面会展示授权用户列表：

| 字段 | 说明 |
|------|------|
| **昵称/用户名** | HDHive 账号信息，可一键隐藏昵称 |
| **授权方式** | 当前为 `gateway` |
| **授权状态** | 正常、失效、需要重新授权 |
| **积分** | 账号剩余积分 |
| **周额度** | 本周已用、剩余和总额度 |
| **VIP 信息** | VIP/永久 VIP 和到期信息 |
| **在线状态** | 最近同步到的账号在线状态 |

顶部统计卡片会汇总本周剩余额度、下周预计额度、今日使用额度、平均每日使用和 VIP 数量。

### 负载均衡

配置多个授权用户后，系统会根据可用额度、状态和活跃配置进行智能调度。授权失效或额度不足的用户会自动跳过，避免搜索和解锁中断。

点击 **刷新全部** 可手动刷新用户信息、积分和额度；系统也会定时同步。

---

## 步骤 3：搜索和解锁资源

进入侧边栏 **HDHive → HDHive 搜索**：

1. 输入关键词，选择电影或电视剧类型
2. 浏览 TMDB 搜索结果
3. 进入详情查看 HDHive 资源列表
4. 点击解锁，系统自动选择可用授权用户

解锁后的资源会进入后续处理：

| 链接类型 | 处理方式 |
|----------|----------|
| 115 分享链接 | 选择 115 账号后一键转存 |
| magnet / ed2k | 提交到 115 离线目录 |
| 已缓存记录 | 可在 **HDHive → HDHive 记录** 查看 |

---

## 步骤 4：配置每日签到

进入 **概览 → 插件库 → HDHive 签到**，为授权用户配置自动签到。

| 配置项 | 说明 |
|--------|------|
| **HDHive 账号** | 选择已完成网关授权的账号 |
| **签到 Cron** | 推荐 `1 0 * * *`，即每天 00:01 |
| **赌狗模式** | 随机增减积分；不想承担扣分风险就保持关闭 |
| **通知 Bot / Chat ID** | 选择发送结果的主 Bot 或副 Bot，并填写接收会话 |

::: tip 推荐设置
普通用户关闭赌狗模式，先手动点一次“立即签到”确认授权和通知都正常，再开启定时任务。
:::

::: caution
签到依赖授权状态。如果用户授权失效，请先在 HDHive 助手中重新授权。
:::

---

## Telegram 与频道监控联动

HDHive 授权用户会被以下功能复用：

- 主 Bot `/search` 搜索和解锁
- 频道监控中的 **启用 HDHive 解锁**
- 手动转发历史消息时的 HDHive 链接替换
- 资源详情生成和 Telegraph 页面处理
- HDHive 解锁记录缓存

这意味着只要中心网关和授权用户配置正常，Web、Bot、频道监控会共享同一套额度池。

# 播放错误说明

播放器未直接开始播放，而是出现带错误编号的提示画面时，可根据编号判断大致原因。

::: important 反馈信息
反馈给管理员时，建议提供错误编号、用户名、影片名称、发生时间和客户端名称。编号类似 `RT-V01`、`RT-V05`，通常会显示在提示画面上。
:::

## 错误码总览

| 编号 | 错误含义 | 建议处理 |
|------|----------|----------|
| `RT-V01` | 账号播放设备数达到限制 | 关闭其他设备播放，等待设备记录释放后重试 |
| `RT-V02` | 115 账号未绑定、失效或认证失败 | 重新绑定或重新登录 115 账号 |
| `RT-V03` | 播放文件临时准备失败 | 稍后重试；持续失败时反馈片名 |
| `RT-V04` | 当前资源文件无法正常获取 | 更换影片测试；仅单片失败时反馈片名 |
| `RT-V05` | 115 返回播放地址受限 | 暂停反复播放，等待限制恢复 |
| `RT-V06` | 短时间重复播放请求过多 | 停止连续重试，等待冷却结束 |
| `RT-V07` | 播放链路出现未归类异常 | 重新登录后重试；持续失败时联系管理员 |

## 各错误说明

### RT-V01 播放设备过多

账号同时播放设备数量超过限制，或历史设备记录尚未释放。

处理建议：关闭其他手机、电视、浏览器或播放器上的播放，等待一段时间后重新打开影片。若实际只有单设备播放但仍触发限制，需要管理员清理旧设备记录或检查账号状态。

### RT-V02 115 账号未就绪

系统无法使用 115 账号完成播放，常见于未绑定、登录过期、Cookie 失效或账号验证失败。

自备 115 账号模式下，建议在用户面板重新扫码登录 115。完整 Cookie 不应通过聊天发送给他人。

### RT-V03 播放准备失败

系统已定位到资源，但临时准备播放文件失败。常见原因包括目标目录不可用、空间不足、当天额度用完，或临时转存没有成功。

处理建议：稍后重试。若同一部影片持续失败，或大量影片同时失败，需要反馈错误编号和片名。

### RT-V04 资源暂不可用

当前影片本身无法正常获取，常见于文件已删除、路径不匹配、分享失效，或资源文件太大导致无法处理。

如果只有这一部影片失败，优先反馈影片名称。如果很多影片都失败，可能是媒体库路径或资源来源有问题，需要管理员统一检查。

### RT-V05 115 服务暂时受限

115 当前没有正常返回播放地址，可能是账号被临时限制、接口繁忙，或下载链路暂时拒绝访问。

处理建议：暂停连续点击播放，等待一段时间后再试。自备 115 账号模式下，可重新扫码登录 115 后重试。

### RT-V06 播放请求过于频繁

短时间内重复点击播放、客户端自动重试过多，或系统正在保护 115 取链请求时，会出现此类提示。

处理建议：停止重试，等待几分钟后再打开影片。如果客户端持续自动弹错或不断重试，建议完全关闭客户端后重新进入。

### RT-V07 播放服务暂时不可用

这是兜底错误，表示系统还没有把问题归到前面几类。可能和登录状态、媒体信息、播放配置、线路或上游服务有关。

处理建议：退出账号并重新登录，然后重新打开影片详情页再播放。若仍然出现，需要反馈错误编号、片名和发生时间。

## 不属于这类错误的情况

有些问题不会显示 `RT-V01` 到 `RT-V07`，但看起来也像“不能播放”：

| 情况 | 更可能的原因 |
|------|--------------|
| 登录失败 | 用户名、密码、账号状态或登录限制问题 |
| 打不开媒体详情 | 账号权限、Token 失效或 Emby 服务异常 |
| 显示没有媒体权限 | 当前账号没有这部影片或媒体库的权限 |
| 有画面但卡顿、黑屏、无声 | 客户端解码能力、本地网络或设备播放器问题 |
| 换播放器后正常 | 原客户端缓存、解码或网络策略不同 |

遇到无法判断的情况，直接把错误编号和现象发给管理员即可。

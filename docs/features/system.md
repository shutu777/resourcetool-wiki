# 系统管理

管理系统全局配置、管理员账号、插件库、品牌定制、备份还原和日志查看。

---

## 第一部分：全局系统配置

进入侧边栏 **系统 → 系统配置**（对应前端路由 `/system-config`），管理 ResourceTool 的全局设置。

### 授权信息

页面顶部展示授权状态：

| 字段 | 说明 |
|------|------|
| **授权状态** | 已授权（绿色）/ 未授权（红色） |
| **授权码** | 密码框显示，可切换明文 |
| **设备 ID** | 当前绑定的设备标识 |
| **到期时间** | 授权到期日期 |
| **授权功能** | 已授权的功能模块列表 |

### 网络代理

| 配置项 | 说明 |
|--------|------|
| **代理地址** | HTTP/HTTPS/SOCKS5 代理地址（如 `http://127.0.0.1:7890`） |

点击「测试连接」按钮可验证代理是否可达。

::: info 智能分流
系统自动按域名进行智能分流：
- **走代理** — Telegram API、TMDB API、Telegraph、HDHive API
- **直连** — 115 网盘 API（国内服务）
:::

### HDHive 中心网关

HDHive 个人 API Key 方式已下架，ResourceTool 现在通过中心网关完成 HDHive 授权。

| 配置项 | 说明 |
|--------|------|
| **中心网关** | 默认官方网关 `https://hdhive-open.resourcetool.pro` |
| **RT 外网地址** | HDHive 授权完成后的回调地址，例如 `https://rt.example.com` |
| **一键接入并启用** | 自动注册当前 RT 实例，写入实例 ID 和密钥 |

接入完成后，到 **HDHive → HDHive 助手** 点击 **网关授权** 添加授权用户。

### TMDB 配置

| 配置项 | 说明 |
|--------|------|
| **TMDB API Key** | 影视搜索的元数据获取（海报、简介、评分等），在 [TMDB 官网](https://www.themoviedb.org/settings/api) 免费申请 |

### 定时任务配置

以下 Cron 表达式控制各定时任务的执行频率：

| 任务 | 默认值 | 说明 |
|------|--------|------|
| **115 Cookie 检测** | `*/10 * * * *` | 在 **插件库 → 115 健康检查** 设置；管理员账号和用户自备账号使用同一计划 |
| **Emby 用户同步** | `0 */3 * * *` | 在 **开服 → 开服配置** 按实例设置 |

::: tip 生命周期任务
Emby 到期扫描已经迁移到 **开服 → 实例管理 → 生命周期任务**，每个实例可以单独配置 Cron、启停任务并立即执行。
:::

### 播放限制

| 配置项 | 说明 |
|--------|------|
| **播放 QPS 限制** | Emby 302 每秒最大播放请求数 |
| **最大等待时间** | 超过 QPS 限制时的最大排队等待时间 |

## 第二部分：备份还原

进入侧边栏 **系统 → 备份还原**。新版备份还原替代旧版配置导入导出，覆盖数据库和运行配置，适合迁移、灾备和版本回退前留档。

### 备份配置

| 配置项 | 说明 |
|--------|------|
| **启用自动备份** | 开启后按 Cron 自动执行 |
| **Cron 表达式** | 自动备份执行时间 |
| **保留天数** | 自动清理过期远端备份 |
| **目标 115 账号** | 备份上传到哪个 115 配置 |
| **备份目录路径** | 默认 `/rt_backup` |
| **上传通道** | 支持 115 OSS 原生上传等通道 |
| **加密密钥** | 使用 AES-256-GCM 加密备份文件 |
| **包含设备 Token** | 迁移到新设备时按需选择 |

点击 **立即备份** 可手动触发。备份完成后会写入历史记录，并可通过 Telegram 通知目标账号。

### 还原流程

1. 在 **远端备份** 列表选择备份文件
2. 点击 **还原**，系统下载并校验 SHA1
3. 状态变为 **待确认还原** 后点击 **确认还原并重启**
4. 服务重启时自动应用 `.restore-pending` 中的备份

::: danger
确认还原会覆盖当前数据并重启服务。执行前建议保留当前数据目录副本，尤其是跨设备迁移时。
:::

## 第三部分：插件库

进入侧边栏 **概览 → 插件库**。新版侧边栏将多个助手能力集中到插件库：

| 插件/助手 | 入口能力 |
|-----------|----------|
| **Emby 助手** | Emby 302 配置、播放网关、缓存、监控等 |
| **115 助手** | 账号 Cookie、扫码登录、VIP/容量、签到、清理 |
| **HDHive 助手** | 网关授权用户、额度刷新、负载均衡 |
| **Telegram 助手** | 主 Bot、MTProto Session、监控基础能力 |
| **CloudDrive2 助手** | CD2 地址、账号、gRPC 加速配置 |
| **飞牛 OS 助手** | FnOS 302 网关配置 |

普通菜单权限会按插件 key 控制，旧菜单 key 会自动映射到新的插件入口。

## 第四部分：管理员账号管理

进入侧边栏 **系统 → 用户管理**（对应前端路由 `/user-management`），管理系统管理员账号：

- **创建管理员** — 添加新的系统用户，分配 `admin` 或 `user` 角色
- **角色权限** — admin 拥有全部权限；user 只能访问被分配的菜单，可在编辑弹窗中勾选允许访问的菜单项
- **个人资料** — 右上角头像下拉 → 个人资料（`/profile`），可修改用户名、密码和上传头像

::: caution 首次登录后请立即修改默认密码（admin/admin）。
:::

## 第五部分：品牌定制

开服版支持自定义面板的品牌标识。右上角头像下拉菜单中：

- **上传 Logo** — 替换面板左上角的 logo 图片
- **自定义标题** — 替换浏览器标签页标题
- **恢复默认** — 一键恢复系统默认品牌标识

## 第六部分：插件市场

进入侧边栏 **概览 → 插件库**（对应前端路由 `/plugin-store`），查看当前可用的独立功能模块：

| 卡片 | 路由 | 功能 |
|------|------|------|
| **115 健康检查** | `/plugin-store/pan115-health` | 一键批量检测所有 115 Cookie 有效性 |
| **115 签到** | `/plugin-store/pan115-signin` | 各 115 账号独立定时签到配置 |
| **115 回收站清理** | `/plugin-store/pan115-cleaner` | 定时清理临时目录和回收站 |
| **CloudDrive2 助手** | `/plugin-store/clouddrive2-assistant` | CD2 gRPC 连接和路径映射 |
| **飞牛 OS 助手** | `/plugin-store/fnos-assistant` | 飞牛 OS（Jellyfin）302 播放网关 |
| **HDHive 签到** | `/plugin-store/hdhive-signin` | HDHive 每日自动签到 |
| **Telegram 助手** | `/plugin-store/telegram-assistant` | Bot Token 和 MTProto Session |
| **Telegram 签到** | `/plugin-store/telegram-signin` | Bot 定时签到任务 |

::: tip 助手入口
「Emby 助手」「115 助手」「HDHive 助手」也使用插件详情页样式，但它们有独立的侧边栏入口，不在插件库卡片中重复展示。
:::

## 第七部分：日志查看

进入侧边栏 **概览 → 系统日志**（对应前端路由 `/logs`），查看实时系统日志：

- **实时输出** — 日志流实时刷新，支持暂停/继续
- **调试模式** — 开启后输出更详细的 DEBUG 级别日志，可在日志页面或右上角菜单中切换
- **日志文件** — 按天轮转，自动保留最近 7 天

## 第八部分：用户自助面板

Emby 用户登录后面向的是用户自助面板（`/my`），而非管理后台：

| 页面 | 路由 | 功能 |
|------|------|------|
| **我的面板** | `/my` | 账号状态、到期时间、115 模式、公告、访问线路、在线会话管理、邀请码兑换 |
| **账号设置** | `/my/settings` | 修改密码、重设 Emby 密码、绑定/解绑 TG、自备 Cookie 管理（支持二维码扫码登录）、上传头像 |
| **求片中心** | `/my/requests` | 搜索 TMDB 提交求片、缺集报告、异常报告、查看历史记录和状态 |

### 自助功能详情

- **邀请码兑换**：用户可在面板中直接输入邀请码续期
- **Cookie 管理**：自备模式用户可填写 115 Cookie 和回收站密码，支持 12 种客户端二维码扫码登录
- **TG 绑定**：生成 5 分钟有效绑定码，在 Bot 中发送 `/bind <code>` 完成绑定
- **会话管理**：查看自己的活跃 Emby 会话并终止异常设备
- **密码同步**：修改后面板密码和 Emby 客户端密码同步更新

## 第九部分：发布页

发布页（`/publish`）是一个无需登录的公开页面，用于向 Telegram 频道提交格式化的媒体资源发布消息。

### 功能流程

1. 粘贴 115 分享链接文本，自动识别标题、TMDB ID
2. 搜索 TMDB 元数据并选择影片
3. 自动获取链接文件大小
4. 选择画质、视频格式、字幕等标签
5. 预览格式化消息 → 提交发布

### 配置项

在系统配置中设置：
- **Telegram Bot Token** — 发送消息的 Bot
- **目标 Chat ID** — 发布到的频道/群组
- **发布页地址** — 生成「投稿」按钮的回链地址

::: tip 支持 `?channel=xxx` URL 参数指定目标频道，配合频道监控的「广告位」和「显示投稿按钮」实现自动化投稿入口。
:::

发布页内置频率限制：每 IP 每 5 分钟最多 10 次提交，超限封禁 1 分钟。

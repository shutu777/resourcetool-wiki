# 监控大屏

监控大屏是一个全屏实时 Emby 服务器监控看板，通过独立 URL 访问，无需登录。适合在电视、平板或副屏上常驻展示。

## 启用监控大屏

在 Emby 302 配置卡的「容器监控」标签页中：

1. 开启 **启用监控大屏**
2. 系统自动生成 64 位 Token
3. 点击「重置」可重新生成 Token

访问地址：
```
https://你的域名/monitor/<64位Token>
```

::: tip 大屏独立于管理面板，无需登录，适合投屏到电视或公用显示器。
:::

## 展示内容

大屏以 1920x1080 画布设计，自适应缩放填充屏幕，移动端自动切换为滚动布局。

| 区域 | 内容 | 刷新频率 |
|------|------|---------|
| **顶部状态栏** | 实例名称、实时时钟、日期星期 | 每秒 |
| **统计卡片** | 今日入库、今日播放、在线用户、正在播放、运行时长 | 实时 |
| **系统状态** | CPU / 内存 / 磁盘环形仪表盘 | 实时 |
| **网络流量** | 上传/下载速率曲线图（最近 20 个采样点） | 2 秒 |
| **存储面板** | 磁盘总用量环形图 + 各分区进度条 | 20 秒 |
| **最近入库** | 最新 8 部媒体海报、标题、年份、画质标签 | 20 秒 |
| **正在播放** | 4 个最新播放会话：海报、标题、用户名、进度条 | 2 秒 |
| **在线用户** | 10 个最新在线用户：用户名、客户端、IP、播放内容 | 2 秒 |
| **系统信息** | 服务器名、操作系统、Emby 版本、启动时间 | 45 秒 |
| **媒体库统计** | 电影数、剧集数、音乐数、总媒体数 | 45 秒 |

## 数据来源

大屏通过 Emby API 实时拉取数据，所有请求经过 ResourceTool 后端代理转发，不直接暴露 Emby 地址。

大屏可正常展示管理员 Cookie 的 115 在线状态信息，但播放统计仅来自 Emby 服务器。

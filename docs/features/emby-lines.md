# 访问线路与会话管理

为 Emby 实例配置多条访问线路，监控在线会话并管理异常设备。

---

## 第一部分：访问线路

当 Emby 有多条接入线路（如不同地区 CDN、不同端口）时，可通过访问线路管理让用户自行选择最优线路。

进入侧边栏 **开服 → 访问线路**：

### 添加线路

1. 顶部下拉选择要配置的 Emby 实例
2. 点击 **添加** 按钮新增一行
3. 填写以下配置：

| 配置项 | 说明 |
|--------|------|
| **线路名称** | 自定义名称（如「深圳电信」「香港 CN2」） |
| **协议** | 选择 `https` 或 `http`，切换时端口自动适配（443↔80） |
| **域名/IP** | Emby 服务器的域名或 IP 地址 |
| **端口** | 访问端口，默认端口时 URL 中不显示 |
| **启用** | 取消勾选后该线路不对用户展示 |
| **隐藏** | 勾选后不对普通用户展示 |
| **白名单可见** | 勾选隐藏后才可设置，白名单和永久用户仍可见 |

4. 按住左侧拖拽手柄调整线路排序
5. 点击 **保存**

### 线路可见性规则

| 用户类型 | 普通线路 | 隐藏线路 | 隐藏+白名单可见 |
|---------|---------|---------|----------------|
| 普通用户 | ✅ 可见 | ❌ 不可见 | ❌ 不可见 |
| 永久用户 | ✅ 可见 | ❌ 不可见 | ✅ 可见 |
| 白名单用户 | ✅ 可见 | ❌ 不可见 | ✅ 可见 |
| 管理员 | ✅ 可见 | ✅ 可见 | ✅ 可见 |

### 线路探测

点击顶部「探测」按钮，系统自动测试所有线路的可用性和延迟：

- <Badge type="tip" text="在线" /> — 显示延迟毫秒数（如 `45ms`）
- <Badge type="danger" text="离线" /> — 线路不可达

::: tip 探测结果仅供参考，实际用户体验还受地理位置和网络环境影响。
:::

## 第二部分：在线会话管理

进入侧边栏 **开服 → 活跃设备**，实时查看所有 Emby 实例的活跃会话。

### 页面概览

顶部有实例选择下拉和自动刷新开关。下方按三个分组展示会话：

| 分组 | 说明 |
|------|------|
| **正在播放** | 当前有播放活动的会话，绿色高亮 |
| **在线** | 已连接但未在播放 |
| **离线** | 最近连接过但已断开 |

### 会话信息

每个会话卡片展示：

| 字段 | 说明 |
|------|------|
| **用户名** | Emby 用户名 |
| **客户端** | 播放器名称和版本（如 Infuse 7.8） |
| **设备名** | 设备标识（如 iPhone 15 Pro） |
| **IP 地址** | 客户端 IP |
| **播放内容** | 当前正在播放的媒体名称 |
| **播放进度** | 进度条 + 已播放时间 / 总时长 |
| **播放方式** | 直接播放 / 转码 |
| **码率** | 播放码率 |

### 终止会话

每个正在播放的会话卡片右上角有「终止」按钮，点击后确认即可强制断开该会话。

::: danger 此操作会立即中断用户的播放，请谨慎使用。
:::

### 自动刷新

页面默认开启自动轮询（约 5 秒一次），可通过顶部开关关闭。

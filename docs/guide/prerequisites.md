# 使用须知

在开始部署之前，建议先了解 ResourceTool 的核心组件和使用场景。

## 三个 Telegram Bot

ResourceTool 内置三个独立的 Telegram Bot，需要在 [@BotFather](https://t.me/BotFather) 中分别创建，获取各自的 Token 后在面板中配置。

:::: card-grid
::: card title="主 Bot（telegram 助手）" icon="material-symbols:smart-toy"
用于资源搜索、HDHive 解锁查看和手动转发脱敏频道消息；没有频道转发需求时可以不配置。可配置群组白名单，让群组成员通过该 Bot 使用 HDHive 搜索。
:::
::: card title="副 Bot（115 助手）" icon="material-symbols:robot-2"
绑定到单个 115 账号，用于监控转存、自动转存和账号级通知。可关联阿里、百度网盘，用户通过 HDHive 搜索后直接转存到该 115 账号。
:::
::: card title="Emby Bot（实例配置）" icon="material-symbols:live-tv"
**开服功能**，面向 Emby 终端用户和管理员。拥有 RT 网页用户端的完整能力和管理端的大部分能力，支持注册、绑定、续期、改密、切换模式、频道入库通知，以及管理员在群聊中直接开通或管理用户。
:::
::::

### 主 Bot

![prerequisites-20260523141233952](/images/prerequisites-20260523141233952.png)

**菜单功能：**

| 菜单按钮 | 说明 |
|---------|------|
| 🔍 搜索影视 | 搜索 TMDB + HDHive 资源，内联按钮查看详情、解锁资源 |
| 👥 HDHive 用户 | 查看所有 HDHive 用户的在线状态、周额度、积分、Premium 等信息 |
| 📡 监控转发 | 查看监控转发规则列表，点击即可切换单项开关 |
| 📋 最新日志 | 查看最近 50 条系统日志 |
| ℹ️ 版本信息 | 查看当前版本号、Bot 名称、运行时间 |

::: details 命令列表
| 命令 | 说明 |
|------|------|
| `/start` | 打开主菜单 |
| `/search 关键词` | 搜索影视资源 |
| `/show_hdhive_users_info` | HDHive 用户详情 |
| `/logs` | 最近日志 |
| `/version` | 版本信息 |
:::

**消息处理：**

- **发送 HDHive 链接** → 自动解锁并展示资源信息
- **手动转发频道消息** → 自动识别消息中的隐藏链接，按频道转发规则处理脱敏后的消息
- **图片/超链接/Telegraph 页面** — 自动提取隐藏的资源链接
- **实时通知** — 频道转发、资源识别、日志等状态推送

::: important
主 Bot 本身**无法**主动监听其他频道消息。要实现自动监听，需要配合 MTProto Session + 频道监控/频道转存功能。
监控转发是通过session账号本身去监控，然后主bot需要拉进频道或者群组内设置管理员。本体监听，bot转发的逻辑。
:::

### 副 Bot（115 助手）

![prerequisites-20260523141339740](/images/prerequisites-20260523141339740.png)
![prerequisites-20260523141408561](/images/prerequisites-20260523141408561.png)

每个 115 账号配置中可以绑定一个独立的副 Bot。副 Bot 复用 Telegram 助手的搜索与菜单能力，并绑定到具体 115 账号处理转存，区别在于：

| | 主 Bot | 副 Bot |
|------|--------|--------|
| **数量** | 1 个 | 每个 115 配置可绑定 1 个 |
| **功能定位** | 搜索、解锁查看、频道转发管理 | 搜索、解锁并转存到绑定的 115 账号 |
| **通知路由** | 通知管理员 | 通知该 115 配置的通知 Chat |
| **访问控制** | 管理员白名单 | 独立的用户白名单和通知 Chat 限制 |

**核心功能：**

- **HDHive 搜索** — 使用 `/search` 或菜单搜索 TMDB + HDHive 资源，结果支持分页、筛选和详情查看
- **搜索结果转存** — 在副 Bot 中点击解锁按钮后，115 资源自动转存到绑定账号，按钮会以转存图标提示
- **HDHive 链接转存** — 直接发送 HDHive 资源链接，解锁成功后自动提取 115、ed2k、阿里、百度链接并处理
- **普通链接转存** — 直接发送 115 分享、magnet、ed2k 链接，转存或离线下载到绑定 115 账号
- **云盘助手联动** — 阿里云盘、百度网盘资源会交给已启用的对应助手转存；未配置时会提示未自动转存
- **隐藏链接提取** — 支持从消息正文、图片说明、超链接实体、内联按钮 URL、Telegraph 页面中提取资源链接
- **合并防抖** — 同一聊天内连续发送多条资源消息时，会在短时间窗口内合并处理并去重
- **重复转存规避** — 如果监听转发链路会转存到同一个 115 账号，副 Bot 会跳过本次重复转存
- **结果通知** — 转存完成后向当前聊天回复，并按配置通知其他 Chat，自动跳过当前聊天避免重复提醒

**配置项：**

| 配置 | 说明 |
|------|------|
| **Bot Token** | 从 @BotFather 获取的该 115 账号专属 Token |
| **AllowedUserIDs** | 允许使用副 Bot 的 Telegram 用户 ID；配置后不在列表中的用户无法使用 |
| **NotifyUserIDs** | 转存通知 Chat ID；配置后副 Bot 只允许这些聊天使用，并向这些聊天发送转存通知 |
| **转存目录** | 115 分享链接转存目录 |
| **离线目录** | magnet / ed2k 离线下载目录；未配置时使用转存目录 |

**使用场景：**

- 管理员管理多个 115 账号，每个账号有独立的 Bot 供对应用户使用
- 被授权的用户可以通过副 Bot 搜索和转存资源到指定 115 账号
- 发送 HDHive 链接后自动解锁并转存到绑定的 115 账号
- 直接发送 115、magnet、ed2k 链接，仍按普通转存处理
- 配置阿里、百度网盘助手后，可联动处理对应资源转存
- 转存完成通知自动路由到副 Bot 的关联用户，不会混乱

### MTProto Session

::: important MTProto Session
除了三个 Bot 之外，还需要配置 MTProto Session 来实现频道自动化。Session 以**你的个人 Telegram 账号**身份登录，可以实时监听已加入的所有频道消息（新消息 + 编辑消息），这是 Bot 无法做到的。
:::

**登录方式：** 验证码 / 二步验证密码 / QR 码扫码

::: caution
Session 登录后，**频道监控**（转发到其他 TG 频道）和**频道转存**（转存到 115 网盘）才能正常工作。未配置 Session 时，频道监控相关功能将无法使用。
:::

## Emby 播放全场景

ResourceTool 的 Emby 播放网关会先识别 STRM 类型，再结合用户的网盘模式决定最终播放链路。配置前建议先确认自己的媒体库属于哪一种 STRM。

| STRM 类型 | STRM 内容特征 | 需要配置 | 适合场景 |
|-----------|---------------|----------|----------|
| **路径类 STRM** | 本地路径、挂载路径、CD2 cloud strm URL | 路径映射，推荐配置 CD2 加速 | CloudDrive2、Rclone、NAS 挂载媒体库 |
| **Pickcode 类 STRM** | URL 中带 `pickcode` 或 `fileId` | Pickcode 模式，按需配置秒传映射 | 已经生成 115 文件标识的媒体库 |
| **分享类 STRM** | URL 中带 `share_code`、`receive_code`、`shareCode` | 分享播放和分享副号 | 未提前转存、依赖 115 分享播放的媒体库 |
| **原生媒体** | Emby 可直接访问真实媒体文件 | 原生播放或原生备用 | 本地盘媒体、测试账号、115 风控时降级 |

::: important 客户端接入方式
Emby 客户端必须连接 RT 的反代端口，不能直接连接 Emby 原始端口。只有播放请求经过 RT，系统才能识别 STRM、执行 302 出链、预缓存、设备流控和网盘模式判断。
:::

### 自备网盘

网盘模式决定最终使用谁的 115 账号出链。它可以来自实例默认权限模板、邀请码、用户管理页，也可以在管理员允许时由用户自助切换。

| 网盘模式 | 出链账号 | 说明 |
|----------|----------|------|
| **共享自动均衡** | emby助手的源账号或者目标账号负载池 | 系统按秒传规则和账号池自动分流 |
| **共享源号直出** | emby助手的源账号 | 始终使用源账号302播放 |
| **共享定向分流** | 额外的目标账号负载池，非emby助手的默认负载池 | 批量指定单个或者多个账号组成的负载池分流 |
| **自备网盘** | 用户自己的 115 Cookie | 适合大规模开服，直链缓存和账号压力按用户隔离 |
| **原生播放** | Emby 服务器 | 跳过 115，直接走 Emby 原始播放链路 |

::: tip 配置顺序
先在 **115 助手**添加内置账号，再在 **Emby 助手**创建播放网关并配置 STRM 模式，最后到 **实例管理 / Emby 用户**设置权限模板和用户网盘模式。完整说明见 [Emby 播放全场景](/features/emby302/)。
:::

# 公告与邀请码

管理面向 Emby 用户的系统公告和注册邀请码（激活码），控制用户注册和消息通知。

---

## 第一部分：公告管理

进入侧边栏 **开服 → 公告管理**，创建和管理面向 Emby 用户的系统公告。

### 创建公告

点击 **新增公告**：

| 配置项 | 说明 |
|--------|------|
| **标题** | 公告标题 |
| **内容** | 公告正文，支持 Markdown 格式 |
| **目标实例** | 选择特定 Emby 实例或「全部实例」 |
| **启用** | 开关，控制公告是否对用户可见 |

### 公告管理

每张公告卡片显示标题、内容预览、目标实例、状态标签。支持以下操作：

- **推送** — 一键广播到对应 Emby Bot 的所有已绑定用户，完成后显示发送成功/失败统计
- **启用/停用** — 快速切换公告可见状态，无需打开编辑弹窗
- **编辑/删除** — 修改公告内容或删除

## 第二部分：邀请码管理

邀请码是控制 Emby 用户注册范围的核心手段。在 [开服配置](/features/emby-security/) 中开启「需要邀请码」后，用户注册时必须提供有效邀请码。

进入侧边栏 **开服 → 邀请码**。

### 邀请码作用

邀请码决定了用户注册后的：
- **用途** — 注册码只能开通新账号，续期码只能给已有账号续期
- **时长档位** — 天卡(1天) / 周卡(7天) / 月卡(30天) / 年卡(365天) / 白名单(永久)
- **网盘模式** — 共享自动均衡 / 自备网盘 / 原生播放等
- **权限模板** — 可绑定实例中的权限模板，决定 Emby Policy、设备数、媒体库权限等
- **所属实例** — 多实例时绑定到哪个 Emby 实例

### 网盘模式说明

| 模式 | 说明 |
|------|------|
| **共享·自动均衡** | 系统按实例秒传规则自动分配 115 账号，多账号负载均衡 |
| **共享·源号直出** | 不经过秒传，始终用存储文件的源账号出直链 |
| **共享·定向分流** | 播放时秒传到指定账号，从该账号出直链 |
| **自备网盘** | 用户必须绑定自己的 115 Cookie 才能播放 |
| **原生播放** | 跳过 302 直链，由 Emby 服务器原生播放 |

### 生成邀请码

**生成单个**：点击按钮，选择配置后立即生成一个邀请码并自动复制，适合即时发给用户。

**批量生成**：点击按钮，配置后一次性生成多个（1~100 个），生成后可一键复制全部。

| 配置项 | 说明 |
|--------|------|
| **数量** | 批量生成时的数量，单个固定为 1 |
| **用途** | 注册新账号 / 续期已有账号 |
| **时长档位** | 天卡 / 周卡 / 月卡 / 年卡 / 白名单(永久) |
| **网盘模式** | 决定用户注册后的网盘使用方式 |
| **权限模板** | 注册后自动套用的模板 |
| **所属实例** | 多实例时选择绑定实例 |

::: tip 默认值
网盘模式和权限模板默认值来自 [实例管理](/features/emby-instances/) 中该实例的默认权限模板。
:::

::: warning 恢复边界
邀请码只能恢复由到期扫描或活跃度检测产生的生命周期禁用用户。管理员手动禁用、风控禁用等普通 disabled 用户不会被邀请码绕过。
:::

### 典型使用流程

1. 在 [开服配置](/features/emby-security/) 中开启「开放注册」和「需要邀请码」
2. 生成时明确选择 **开号**；界面默认是续费码，续费码不能注册新账号
3. 根据需求选择时长档位、网盘模式和权限模板，生成邀请码
4. 将邀请码发送给用户
5. 用户注册时输入邀请码，系统校验用途、实例匹配和使用状态
6. 在列表中追踪每个邀请码的使用情况

### 邀请码列表

| 列名 | 说明 |
|------|------|
| **邀请码** | 随机生成的字符串，可选中复制 |
| **用途** | 注册码 / 续期码；历史兼容码仍可用于两种场景 |
| **实例** | 所属 Emby 实例 |
| **天数** | 有效天数，白名单码显示「白名单」 |
| **模式** | 网盘模式 |
| **状态** | <Badge type="tip" text="未使用" /> / <Badge type="info" text="已使用" /> |
| **使用者** | 已使用时显示用户和日期 |
| **创建时间** | 创建时间 |

支持按实例筛选、分页浏览、批量选择删除。

::: warning 多实例环境下，邀请码绑定了特定实例。用户注册时选择的实例必须与邀请码的实例一致，否则兑换失败。
:::

# 求片系统

对应前端侧边栏 **开服 → 求片管理**，管理用户通过 Bot 或用户面板提交的影视求片请求。

::: important 前置条件
求片系统需要先在 [实例管理](emby-instances.md) 中开启「启用求片」开关，并在 Emby 302 配置中设置 TMDB API Key 才能正常使用。
:::

## 工作流程

新版既可以人工处理，也可以让系统定时自动找片：

```
用户搜索 TMDB → 确认影片 → 填写备注 → 提交求片
                                              ↓
管理员查看 → 自动找片或人工处理 → 用户收到通知
```

### 用户端（Bot / 用户面板）

用户可以通过两种方式提交求片：

**通过 Bot：**

::::: steps

1. **发起搜索**

   在 Bot 中使用菜单进入求片功能，输入想要搜索的影片名称

2. **选择影片**

   Bot 返回 TMDB 搜索结果列表，包含海报、年份、类型等信息，点击选择目标影片

3. **选择求片类型**

   - **新片求片** — 媒体库中没有的影片
   - **缺集报告** — 剧集缺少某些集数
   - **异常报告** — 影片存在画质、字幕等问题

4. **填写备注（可选）**

   补充说明需求细节，如「缺少第 5 集」「字幕不同步」等

5. **提交**

   确认后提交求片请求，系统通知管理员

:::::

**通过用户面板：**

用户面板中的「我的求片」页面提供相同的搜索和提交功能，以卡片形式展示历史求片记录和当前状态。

### 求片频率限制

为防止滥用，每个用户在限制周期内的求片次数受到限制。默认每 7 天最多 3 次电影求片和 3 次剧集求片，管理员可在 [实例管理](emby-instances.md) 的求片系统配置中调整。

## 管理员端（求片管理页面）

### 页面结构

页面顶部显示统计卡片（总求片数、待处理、已完成、已拒绝），下方为筛选栏和求片列表。

### 筛选与搜索

| 筛选项 | 说明 |
|--------|------|
| **实例选择** | 多实例时可按实例筛选 |
| **片名搜索** | 按影片名称关键词搜索 |
| **用户名搜索** | 按提交用户的用户名搜索 |
| **状态筛选** | 全部 / 待处理 / 已完成 / 已拒绝 |
| **类型筛选** | 全部 / 新片求片 / 缺集报告 / 异常报告 |

剧集请求会保存具体季号，例如“第 2 季”。同一部剧的不同季可以分别提交和处理，自动找片也会优先排除季号明显不匹配的资源。

### 求片列表

每条记录显示以下信息：

| 字段 | 说明 |
|------|------|
| **影片信息** | TMDB 海报缩略图、中英文片名、年份、类型（电影/剧集） |
| **用户** | 提交求片的 Emby 用户名 |
| **求片类型** | 新片求片 / 缺集报告 / 异常报告 |
| **备注** | 用户填写的补充说明 |
| **状态** | <Badge type="warning" text="待处理" /> / <Badge type="tip" text="已完成" /> / <Badge type="danger" text="已拒绝" /> |
| **时间** | 提交时间 |

### 处理求片

::::: steps

1. **查看待处理请求**

   将状态筛选设为「待处理」，查看所有等待处理的求片

2. **完成求片**

   资源已入库后，点击「完成」按钮，系统自动通知用户求片已完成

3. **拒绝求片**

   无法满足的请求，点击「拒绝」按钮，系统自动通知用户

4. **删除记录**

   已完成或已拒绝的记录可点击「删除」清理

:::::

## 自动找片

在 **开服 → 实例管理 → 求片系统** 中开启。系统会按 Cron 扫描待处理请求，从 HDHive、Telegram 中找候选资源，自动解锁并转存到指定 115 目录。

::: tip 推荐设置
- Cron：`*/10 * * * *`（每 10 分钟一次，源码默认值）
- 来源：先只开 **HDHive**；Telegram 索引稳定后再打开
- 目标账号：明确选择一个内置 115 账号，不要依赖临时选择
- 转存目录：单独建 `/求片`，方便检查和整理
- 自动解锁积分上限：先设较保守的值，观察一周命中质量后再提高
:::

找片失败不会把请求直接关掉，而是继续保留“待处理”，方便下次任务重试或管理员手动处理。

::: info Telegram 来源从哪里来
Telegram 自动找片复用 **补漏 → Telegram 搜索** 中配置的频道和本地索引。仅登录 Session 并不会自动搜索所有已加入频道；需要先添加资源来源并同步索引。详细步骤见 [Telegram 资源搜索](/features/telegram/#第七部分-telegram-资源搜索)。
:::

## MoviePilot v2 订阅

ResourceTool 2.1.0 起，每个 Emby 实例都可以生成独立的 MoviePilot 订阅地址。播放器或支持 MoviePilot v2 订阅协议的客户端，可以用这个地址直接发起求片。

1. 进入 **开服 → 实例管理**，展开目标实例
2. 打开 **MoviePilot 订阅**，保存实例
3. 复制系统生成的 RT 订阅地址
4. 在播放器中填写该地址，以及 ResourceTool/Emby 的账号密码

管理员账号提交时会优先立即找片；普通 Emby 用户提交后进入该实例的自动找片队列。删除 MoviePilot 里的订阅不会误删 ResourceTool 中的求片记录。

::: warning 订阅地址要保密
地址中带有随机 Token。怀疑泄露时点击“重新生成”，旧地址会立即失效；随后记得在播放器里换成新地址。
:::

::: tip 移动端适配
移动端自动切换为卡片视图，操作按钮显示在卡片底部，桌面端鼠标悬停在行上显示操作按钮。
